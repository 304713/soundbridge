# 声桥 v1.5.0

界面重做、断开连接的问题修掉了、内存降了一半。建议所有旧版本升级。

## 界面重做

窗口从 880×852 的八段竖排，改成 **780×466 的双栏**（左设备、右设置），一屏放完不用滚，1366×768 也装得下。

- 主按钮贴着设备列表，不再夹在两张说明卡中间
- 「一副耳机，两个东家」这类介绍文案从主界面移走，收进「使用说明」
- 状态原来在三个地方各说一遍，现在只有顶部胶囊 + 一行「出声设备：…」
- 设置按「播放到 / 定时断开 / 开关」三段分组，不再挤在一个卡片里
- 字号从 7 档压到 3 档，开关统一左对齐

## 断开连接：修了三个漏洞

之前点「断开」后手机又连回来，原因不在按钮本身（按钮和蓝牙链路都是真断的），而在断开之后的流程：

1. **掉线重连不看用户意图**。你点断开时如果正好有个掉线回调在路上，它会在 800 毫秒后把连接接回来。
2. **在途的连接尝试可能在你点断开之后才成功**，手机于是又连上了。
3. **睡眠唤醒只判断「睡前是否连着」**，会推翻你手动断开的选择。

现在用一个「用户意图版本号」把这些路径全部钉死：每次点断开就 +1，所有在途连接和迟到的回调发现版本对不上就立刻收手。另外加了一个「保持断开」标记，一直有效到你下次点「连接」——不会再睡一觉起来又被连回去。

顺带修了两处：

- 连接过程加了 **10 秒超时**。蓝牙栈偶尔会卡住不返回，以前会让命令永久处于执行中，按钮从此点不动，用户只觉得「点了没反应」。
- 掉线重连改成**先查蓝牙链路还在不在**：链路没了（手机走远、在系统里断开）就不重连，链路还在才重试。重连过程中主按钮变成「停止重连」，不会摆一个「连接」按钮让人不知道该点哪个。

## 新手引导

首次打开的那一页重写成了三块：**30 秒自检 → 三步出声 → 连不上对照表**。

- 自检把「蓝牙适配器要支持 A2DP Sink」和「系统要 19041 以上」摆在最前面，并说明怎么判断（列表里有没有你的手机）
- 三步里补了最容易卡住的一步：连接时手机上可能弹确认框；有的手机要在手机端反向点一下电脑才会发起音频连接
- 故障对照表把五种常见现象和原因并排列出来，比原来大段文字好扫
- 窗口按屏幕工作区自动收高，小屏上底部按钮不会再被挤出去

「使用说明」和「隐私」现在都是**非模态**窗口（以前是模态，开着的时候点主界面任何按钮都没反应），重复点击只会把已有窗口提到前面，不会叠窗。

## 轻量化

发布方式从「压缩单文件」改成「文件夹 + zip」：

| | v1.4.0 | v1.5.0 |
|---|---|---|
| 私有内存 | 153 MB | **73 MB** |
| 工作集 | 301 MB | 162 MB |
| 启动到窗口出现 | 1174 ms | **730 ms** |
| 下载体积 | 72.6 MB | 67.7 MB |

原因在压缩单文件本身：它运行时要把程序集解压进内存才能加载。空窗口对照测试里，压缩单文件 110 MB、普通文件夹 57 MB。代码没变，省下的是解压开销。

**代价**：要先解压再双击，不能从压缩包里直接运行。

`PublishReadyToRun` 也测了，启动再快 60–70 毫秒、包体 +8.6 MB，不划算，没开。

空闲 CPU 实测 0.00%（18 秒采样 0 毫秒），托管堆 7.1 MB，GC 占用 0%。

## 隐私

- 日志里的蓝牙地址**只保留前 4 位**（`FCD9********`）。以前是完整 MAC，你把日志贴出来求助会连带暴露。
- 「隐私」从白底弹窗换成和界面一致的深色窗口，把「音频 / 网络 / 本地文件 / 日志内容」四件事分列说清楚，末尾附彻底清除的方法。

- 说明窗口和隐私窗口补上了品牌图标（原来是空白默认图标）
